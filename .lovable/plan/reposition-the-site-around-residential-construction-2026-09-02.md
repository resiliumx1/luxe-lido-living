# Reposition the Site Around Residential Construction

## What will change

### 1. Rebuild the Services page content
- Replace the current six services, in order, with:
  1. Traditional Construction
  2. Container Builds
  3. Insulated Panel Builds — clearly identified as the recommended method
  4. Renovations & Trades
  5. Property Sales & Land
  6. Relocation Services
- Rewrite the page introduction and closing CTA around building, renovation, land, and property enquiries.
- Make every service row link to the existing contact enquiry flow with its service context in the URL.
- Add a short “Two Ways to Work” section using the existing visual patterns: **Done For You** and **Buyer Managed**.

### 2. Reframe the homepage and About content
- Update the homepage hero, service summary, featured-property framing, construction section, agent biography, Antigua intro, testimonials/newsletter wording, stats labels, and enquiry prompts so construction is the primary business and property sales remain one offering.
- Rewrite About biography, specialties, quote, image alt text, and CTA to speak equally to local homeowners and overseas buyers.
- Keep luxury homes visible as a property category without presenting exclusivity as the company identity.

### 3. Update supporting pages and shared site copy
- Revise public page intros and section labels where they use exclusive/HNW language, including Properties, Luxury Homes, Prefab/insulated-panel content, Contact, navigation CTA wording, and Footer positioning.
- Update enquiry choices to match the six current services while preserving the existing form and backend submission behavior.
- Keep dedicated container-order and trailer-build flows intact; general construction services will use the current contact enquiry flow.

### 4. Remove discontinued service language
- Delete all customer-facing references to Airbnb management, property management, rentals, and car rental from components, page copy, property descriptions/features, and navigation/footer entries if present.
- Remove related outdated “concierge,” “white-glove,” “discerning buyer,” “family office,” “trophy villa,” “private preview,” and similar exclusivity-led positioning.

## Technical details
- Content and information architecture only: no changes to design tokens, fonts, colours, spacing, animation, or reusable layout styling.
- Existing components and routes will be reused; no new visual system will be introduced.
- Query-string service context will be read by the existing contact form so a clicked service arrives preselected.
- After editing, run targeted tests/build verification plus repository searches for discontinued services and exclusivity-led phrases.
